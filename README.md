## 📌 About the Project

**BloomBasket** is a front-end flower shop website where users can explore a curated collection of flower bouquets for different occasions. The project focuses on building a clean, real-world shopping experience using only HTML, CSS, and JavaScript — no frameworks, no libraries.

Built as a portfolio project to demonstrate DOM manipulation, state management, local storage, and responsive UI design skills.

---

## ✨ Features

- 🔍 **Search** — Live debounced search across product names and categories
- 🏷️ **Filter by Occasion** — Birthday, Wedding, Anniversary, Valentine
- 🔃 **Sort** — By price (low → high, high → low) or top rated
- ⭐ **Ratings & Reviews** — Star ratings displayed per product
- 🛒 **Cart** — Add, increase, decrease, remove items with live total
- 🧾 **Order Summary Modal** — Itemized checkout (no `alert()`!)
- 💾 **Local Storage** — Cart and wishlist survive page refresh
- 📱 **Fully Responsive** — Mobile, tablet, and desktop
- 🌸 **Hero Section** — Background image with stats bar
- 🦶 **Footer** — Brand info, quick links, contact details

## 🚀 Getting Started

No installs. No build tools. Just open and run.

```bash

git clone https://damini11-blip.github.io/bloombasket.git

# Open in browser
cd bloombasket
open index.html
```

Or just download the ZIP and open `index.html` in any browser.
